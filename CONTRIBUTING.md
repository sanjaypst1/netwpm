# Contributing

This is a personal portfolio. Changes should preserve the evidence rules.

1. Do not invent employer systems, metrics, team sizes, technologies or results.
2. If a detail is not in the CV, label it in `types/EvidenceStatus` and show the badge on the page.
3. Keep confirmed CV metrics in `data/metrics.ts` only.
4. Run `npm run typecheck`, `npm run lint`, `npm test` and `npm run build` before opening a pull request.
5. Do not commit secrets, `.env` files or confidential employer artefacts.
